# Техническое задание (ТЗ) на Спринт 1
## Описание проекта:
**SPA-приложение для ведения и анализа истории торговых сделок.**

### Функциональные требования:

1. Главная страница (Дашборд):

- Вывод списка всех сделок в виде таблицы или карточек.

- Отображение вложенных данных: для каждой сделки должен отображаться привязанный к ней Алгоритм (название, тип).

- Вывод дат открытия (`openDate`) и закрытия (`closeDate`).

2. Страница добавления сделки:

- Форма (`React Hook Form`) с полями: Инструмент (строка), Дата открытия (дата/время), Дата закрытия (дата/время), Прибыль/убыток (число), Выбор алгоритма (селект).

- Строгая валидация через `Zod`: дата закрытия не может быть раньше даты открытия, инструмент обязателен, прибыль/убыток должен быть числом.

### Технические требования:

- Архитектура: Строгий `Feature-Sliced Design`.

- Стилизация: `CSS Modules` или `SCSS`. Обязательное использование семантических тегов (`<main>`, `<section>`, `<article>`, `<time>`) и Flexbox/Grid для лейаута.

- Стейт-менеджмент и API: `RTK Query`. API-клиент необходимо сгенерировать автоматически (рекомендую использовать `Orval`) на основе `OpenAPI`-спецификации, которую отдает наш локальный бэкенд.
